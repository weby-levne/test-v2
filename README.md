# DrawCraft v3

Jednosouborová aplikace pro GitHub Pages. HTML, CSS a JavaScript jsou uvnitř `index.html`.

## Nasazení
Nahraď starý `index.html` novým souborem a commitni do větve `main` v kořeni repozitáře. GitHub Pages má používat `main` a `/ (root)`.

## Vylepšení
- propracovanější menu a vlastní SVG ikony
- kreslení myší i dotykem, tvary a text
- výběr, přesun a úchyty pro změnu velikosti
- palety barev a nastavení tloušťky
- undo/redo, PNG export
- lokální autosave v prohlížeči
- uložit/obnovit poslední projekt
- import a export projektového JSON
- základní 3D prototyp

Poznámka: lokální projekty zůstávají v daném prohlížeči a zařízení. Pro jistotu exportuj důležité práce jako JSON. Reklama je pouze placeholder. 3D převod je prototyp, ne profesionální modelovací engine.


## Volitelné účty a cloudová knihovna (Supabase)

Účet je dobrovolný. Bez připojení Supabase funguje lokální kreslení a ukládání dál. Pro skutečné přihlášení a synchronizaci napříč zařízeními je potřeba nastavit bezplatný projekt Supabase:

1. Vytvoř projekt na https://supabase.com/ a otevři **Project Settings → API**.
2. V `index.html` najdi `DC_SUPABASE_URL` a `DC_SUPABASE_ANON_KEY` a vlož Project URL a **publishable/anon public key**. Nikdy nevkládej `service_role` / secret key do webové aplikace.
3. V Supabase otevři SQL Editor a spusť:

```sql
create table if not exists public.drawcraft_projects (
  id bigint generated by default as identity primary key,
  user_id uuid not null references auth.users(id) on delete cascade,
  name text not null default 'Moje kresba',
  objects jsonb not null default '[]'::jsonb,
  updated_at timestamptz not null default now()
);

alter table public.drawcraft_projects enable row level security;
create policy "Users can read own DrawCraft projects"
  on public.drawcraft_projects for select to authenticated
  using ((select auth.uid()) = user_id);
create policy "Users can create own DrawCraft projects"
  on public.drawcraft_projects for insert to authenticated
  with check ((select auth.uid()) = user_id);
create policy "Users can update own DrawCraft projects"
  on public.drawcraft_projects for update to authenticated
  using ((select auth.uid()) = user_id)
  with check ((select auth.uid()) = user_id);
create policy "Users can delete own DrawCraft projects"
  on public.drawcraft_projects for delete to authenticated
  using ((select auth.uid()) = user_id);
```

4. V **Authentication → URL Configuration** nastav Site URL na adresu svého GitHub Pages webu. Přidej ji také mezi Redirect URLs.
5. V **Authentication → Providers → Email** nastav potvrzování e-mailu podle toho, jak chceš registraci provozovat.
6. Nahraj aktualizovaný `index.html` do GitHub repozitáře. Účty a cloudové projekty pak poběží po doplnění klíčů a SQL.

Supabase má bezplatný tarif s limity a podmínkami, které se mohou měnit. V aktuálním kódu se projekty ukládají jako data objektů; PNG náhledy zatím cloudová knihovna negeneruje. Cloudové funkce před veřejným spuštěním otestuj s více účty.


## Přihlášení e-mailem a heslem

Google Cloud Console ani SMS provider nejsou potřeba. Pro funkční registraci a cloudovou knihovnu ale musíš propojit aplikaci se Supabase:

1. Vytvoř projekt na https://supabase.com/ a otevři **Project Settings → API**.
2. V `index.html` najdi `DC_SUPABASE_URL` a `DC_SUPABASE_ANON_KEY` a vlož Project URL a **publishable/anon public key**. Nikdy nevkládej `service_role` / secret key do webové aplikace.
3. V Supabase otevři SQL Editor a spusť SQL z části výše, aby se vytvořila tabulka `drawcraft_projects` a bezpečnostní pravidla.
4. V **Authentication → URL Configuration** nastav Site URL na adresu svého GitHub Pages webu. Přidej ji také mezi Redirect URLs.
5. V **Authentication → Providers → Email** nech povolenou e-mailovou registraci. Pokud je zapnuté potvrzování e-mailu, nový uživatel musí potvrdit odkaz, který mu přijde do schránky.
6. Nahraj aktualizovaný `index.html` do GitHub repozitáře a otestuj registraci, přihlášení i ukládání projektů.

Supabase má bezplatný tarif s limity a podmínkami, které se mohou měnit. Bez připojení Supabase dál funguje kreslení a lokální ukládání; účty a cloudové ukládání vyžadují dokončení nastavení výše.
