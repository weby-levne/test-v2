# DrawCraft v3

Jednosouborová aplikace pro GitHub Pages. HTML, CSS a JavaScript jsou uvnitř `index.html`.

## Nasazení
Nahraď starý `index.html` novým souborem a commitni do větve `main` v kořeni repozitáře. GitHub Pages má používat `main` a `/ (root)`.

## Vylepšení
- propracovanější menu a vlastní SVG ikony
- kreslení myší i dotykem, tvary a text
- výběr, přesun a úchyty pro změnu velikosti
- palety barev a nastavení tloušťky
- undo/redo, PNG export
- lokální autosave v prohlížeči
- uložit/obnovit poslední projekt
- import a export projektového JSON
- základní 3D prototyp

Poznámka: lokální projekty zůstávají v daném prohlížeči a zařízení. Pro jistotu exportuj důležité práce jako JSON. Reklama je pouze placeholder. 3D převod je prototyp, ne profesionální modelovací engine.
